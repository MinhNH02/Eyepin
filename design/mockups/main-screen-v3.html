Luồng làm việc trên một job

  1. Mở job: tool đọc nhãn có sẵn và tải ảnh (lưu đệm trên đĩa máy).
  2. Chia đoạn theo người nếu job có nhiều người.
  3. Ở frame đầu và mỗi frame mắt đổi dáng, đặt 4 điểm mỗi mắt; tool suy ra 4 điểm còn lại.
  4. Tool bám theo mắt qua các frame sau và đánh dấu frame "cần ghim" khi không chắc.
  5. Ở frame mắt bị che, tool gợi ý khoé bị che; bạn chấp nhận hoặc kéo lại.
  6. Bấm Quét để soát, rồi Xuất file import (chứa mọi nhãn của job; tool lưu bản sao nhãn cũ trước).
  7. Import file vào job trong CVAT (CVAT local: tool tự import; server công ty: bạn hoặc Codex import).
1. Vẽ bằng 4 điểm
  • Ghim 14, 16, 18, 20 / 22, 24, 26, 28.
  • Tool suy ra 4 điểm còn lại theo tỉ lệ guideline.
2. Bám giữa các frame ghim
  • Vị trí: bám theo ảnh, không model.
  • Dáng mắt: giữ từ frame ghim; đổi dáng thì ghim.
  • Keyframe ghi ra luôn đủ 8 điểm.
3. Khoé bị che tính năng chính
  • Khớp dáng mắt của chính người đó.
  • Gợi ý kèm sai số, tự đặt trạng thái.
4. Hai ảnh nhỏ đo pixel
  • N−1 để so sánh, N+1 cho thấy sẽ đổi bao nhiêu.
  • Vàng trên 8 px, đỏ trên 15 px.
5. Quét
  • Đỏ: sai luật. Vàng: đáng nghi.
  • Bấm để nhảy tới frame đầu mỗi đoạn lỗi.
6. Xuất file import
  • Một file "CVAT 1.1" chứa mọi nhãn của job.
  • Đọc lại sau import để đối chiếu.
